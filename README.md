# Homebrew tap for ChronoStack

[ChronoStack](https://github.com/Asmodeus14/ChronoStack): Stripe Test Clocks for your Docker Compose stack.

```sh
brew install asmodeus14/tap/chronostack
```

Works on macOS (Apple silicon and Intel) and Linux (x86_64 and arm64). ChronoStack needs Docker with Compose v2.

Upgrade with `brew upgrade chronostack`.

The formula installs the prebuilt binaries from the [ChronoStack releases](https://github.com/Asmodeus14/ChronoStack/releases), checked against their SHA-256 sums. ChronoStack is in alpha.
